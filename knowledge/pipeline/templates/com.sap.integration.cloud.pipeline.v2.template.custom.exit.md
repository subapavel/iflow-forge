# Pipeline v2 Template - Custom Exit (com.sap.integration.cloud.pipeline.v2.template.custom.exit)

Artifact: `com.sap.integration.cloud.pipeline.v2.template.custom.exit` 1.0.2, package templates, label 2026-06-trial.

## Purpose

Exit flow listening on `{{ProcessDirect_EndPoint}}` [com.sap.integration.cloud.pipeline.v2.template.custom.exit, adapter "ProcessDirect" "Sender"], writes the calling step into the message processing log [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/addCalledByPipelineStep.groovy#L11] and routes on header customXPipelineStep to one empty Content Modifier per value '01' to '07' [com.sap.integration.cloud.pipeline.v2.template.custom.exit, resource "scenarioflows/integrationflow/PIP_03_InboundConversion4Scenario1.iflw"]. The eight generic iFlows of Step01 to Step06 call a copy by Request Reply as their pre-processing exit, the seven Step07 templates as their post-processing exit (Callers, under Adapters). A scenario copies this template when: it needs own logic in a generic step's pre-processing exit or a Step07 copy's post-processing exit, one route per customXPipelineStep value [com.sap.integration.cloud.pipeline.v2.template.custom.exit, manifest "Bundle-Name"] [com.sap.integration.cloud.pipeline.v2.template.custom.exit, step "Which pipeline step?"].

### Callers

Generic callers: CustomXType = CustomXPre, then step "Call custom exit" runs local process "Call custom exits (global and scenario-specific)" with a scenario call (participant CustomXScenario, `${property.CustomXEndpoint}`) and a global call (CustomXGlobal, `${property.CustomXGlobalEndpoint}`); the global call runs when "Global exit?" finds CustomXGlobalBoolean = 'true', which "Initialize exit" copies from property CustomXPreGlobal_Enabled. Step07 templates: one call (CustomExit, `${property.CustomXPost_Endpoint}`) in their post-processing local process. The generic callers set customXPipelineStep, when absent, to the two digits after "generic.step" in the camelId.
