## The tenant's installed version

Package version: "How to read". An artifact's version is the Bundle-Version of its META-INF/MANIFEST.MF, a separate number: Step01 IDoc is 1.0.8 [2026-06-trial: com.sap.integration.cloud.pipeline.v2.generic.step01.inbound.processing.idoc, manifest "Bundle-Version"] under Generic Inbound 1.0.7 [2026-06-trial/generic-inbound/CHANGELOG.txt#L5], 1.0.9 [2026-09-current: com.sap.integration.cloud.pipeline.v2.generic.step01.inbound.processing.idoc, manifest "Bundle-Version"] under 1.0.8 [2026-09-current/generic-inbound/CHANGELOG.txt#L5]. The tenant profile (part 2) records the package versions as `{{tenant.pipeline.version.generic_inbound}}`, `{{tenant.pipeline.version.generic_outbound}}`, `{{tenant.pipeline.version.generic_pipelines}}`, `{{tenant.pipeline.version.templates}}` (naming.md). Does the customer's version have X: find X's row; X is there when its since is at or below the tenant's version of that package.
