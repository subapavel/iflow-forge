## Placeholders (draft from Pass A; Task 8 completes)

- `{{tenant.pipeline.prefix}}`: the pipeline queue and address prefix; parameters PipelinePrefix (Step01 XI), DefaultJMSQueuePrefix (Step01 IDoc), PipelineJMSQueuePrefix (Step02)
- `{{tenant.endpoint.xi.inbound}}`: address of the Step01 XI sender adapter (parameter XIEntryPoint)
- `{{tenant.endpoint.idoc.inbound}}`: address of the Step01 IDoc sender adapter (parameter IDocEntryPoint)
- `{{tenant.endpoint.custom.preprocessing.global}}`: ProcessDirect address of the global pre-processing exit (parameter CustomXPreGlobal_Endpoint)
- `{{tenant.endpoint.custom.error}}`: ProcessDirect address of the custom error flow (parameter CustomXError_Endpoint)
- `{{tenant.security.sender.role}}`: role required of senders (parameter UserRole)
- `{{tenant.security.cert.subjectdn}}`: subject DN of the sender client certificate (parameter SubjectDN)
- `{{tenant.security.cert.issuerdn}}`: issuer DN of the sender client certificate (parameter IssuerDN)
- `{{tenant.xi.communication.party}}`: XI receiver communication party of the Step01 XI sender adapter (parameter CommunicationParty)
- `{{tenant.idoc.logicalsystem.default}}`: value of parameter Default_LogicalSystemName (Step01 IDoc)
- `{{tenant.name}}`: the tenant name the runtime reads from the environment variable TENANT_NAME; Partner Directory parameter id of the landscape stages (PID SAP_Integration_Suite_Landscape) and part of the stageRule_<tenant name> keys (Step02 async and sync, Step04)
- `{{tenant.pipeline.outbound.suffix}}`: suffix of the Step06 queue `<prefix>Q04<suffix>` and its DLQ (parameter PipelineJMSQueueSuffix; empty unless a receiver-specific outbound processing flow is set up)
- `{{tenant.endpoint.idoc.outbound}}`: ProcessDirect address of the Step08 IDoc flow (parameter ProcessDirect_Address)
- `{{tenant.endpoint.xi.outbound}}`: ProcessDirect address of the Step08 XI flow (parameter ProcessDirect_EndPoint)
- `{{tenant.cloudconnector.location}}`: Cloud Connector location ID of the Step08 receivers (parameter LocationID)
- `{{tenant.idoc.receiver.address}}`: default IDoc endpoint of the receiving system (parameter IDoc_Address)
- `{{tenant.idoc.receiver.credential}}`: default credential alias for Basic authentication (parameter IDoc_CredentialName)
- `{{tenant.idoc.receiver.keyalias}}`: default private key alias for client certificates (parameter IDoc_PrivateKeyAlias)
- `{{tenant.idoc.edidc.sender}}`: default EDIDC sender port, partner type and partner (parameters Default_SNDPOR, Default_SNDPRT, Default_SNDPRN)
- `{{tenant.idoc.edidc.receiver}}`: default EDIDC receiver port, partner type and partner (parameters Default_RCVPOR, Default_RCVPRT, Default_RCVPRN)
- `{{tenant.xi.receiver.address}}`: default XI endpoint of the receiving system (parameter XI_Address)
- `{{tenant.xi.receiver.credential}}`: default credential alias for Basic authentication (parameter CredentialName, Step08 XI)
- `{{tenant.xi.receiver.keyalias}}`: default private key alias for client certificates (parameter XI_PrivateKeyAlias)
- `{{tenant.xi.sender.default}}`: default XI sender component and party (parameters XI_Sender, XI_SenderParty)
- `{{tenant.xi.receiver.default}}`: default XI receiver component and party (parameters XI_Receiver, XI_ReceiverParty)
- `{{tenant.jms.queue.inbound}}`: pipeline inbound queue a Step01 template copy writes to (parameter JMS_Outgoing, templates step01 eo and alo)
- `{{tenant.endpoint.pipeline.sync}}`: ProcessDirect address of the synchronous pipeline entry a Step01 synchronous template copy calls (parameter Sync_Pipeline_Endpoint)
- `{{tenant.endpoint.inbound.conversion}}`: ProcessDirect address of a scenario's inbound conversion flow, registered as Partner Directory InboundConversionEndpoint (parameter ProcessDirect_EndPoint, template step03)
