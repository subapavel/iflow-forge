# checkWellFormedXML

## Purpose

Tests whether the body parses as XML: XmlSlurper parses it, and header isWellFormedXml becomes 'true', or 'false' when the parse throws; the value is written to the audit log [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/checkWellFormedXML.groovy#L5] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/checkWellFormedXML.groovy#L7] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/checkWellFormedXML.groovy#L8] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/checkWellFormedXML.groovy#L10] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/checkWellFormedXML.groovy#L12] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/checkWellFormedXML.groovy#L16] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/checkWellFormedXML.groovy#L17] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/checkWellFormedXML.groovy#L19].
Script step "Check well formed XML" at the start of Step02 inbound processing, both integrated messaging runtimes (async twice), Step04, Step05 and Step06, before the store step or the router "XML?"; Step08 IDoc and XI run a 22-line variant as "Check if XML body" (Variants).
