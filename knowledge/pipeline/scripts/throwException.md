# throwException

## Purpose

Throws an exception built from the properties exceptionMessage, exceptionType and location, so that the step fails on purpose [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/throwException.groovy#L6] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/throwException.groovy#L7] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/throwException.groovy#L8] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/throwException.groovy#L34].
Script step "Throw exception" or "Throw Exception" right after a "Set custom status" Content Modifier in Step01 IDoc and XI, both integrated messaging runtimes and Step08 IDoc and XI; three variants exist (Used by).

- Setters: each calling "Set custom status" sets exceptionMessage and SAP_MessageProcessingLogCustomStatus, for example [com.sap.integration.cloud.pipeline.v2.generic.step01.inbound.processing.idoc, step 49 "Set custom status"]; only the Step08 ones also set location, for example IDocGenericOutboundValidation [com.sap.integration.cloud.pipeline.v2.generic.step08.outbound.processing.idoc, step 10 "Set custom status"] [com.sap.integration.cloud.pipeline.v2.generic.step08.outbound.processing.xi, step 12 "Set custom status"]. ## Gotchas

- An exceptionType outside the four names, a misspelling included, falls silently to Exception [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/throwException.groovy#L30] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/throwException.groovy#L31]; since no caller sets exceptionType, every call in the label throws java.lang.Exception [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/throwException.groovy#L7].
- With an empty exceptionMessage the whole body becomes part of the exception text [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/throwException.groovy#L12].
- The text always ends with " at <location>.", so it carries the default location when the caller sets none [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/throwException.groovy#L8] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/throwException.groovy#L14].
