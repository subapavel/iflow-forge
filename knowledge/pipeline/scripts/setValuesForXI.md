- Because (1) tests containsKey, a header that is present with value "" still wins over the default [com.sap.integration.cloud.pipeline.v2.generic.step08.outbound.processing.xi, scripts/setValuesForXI.groovy#L42] [com.sap.integration.cloud.pipeline.v2.generic.step08.outbound.processing.xi, scripts/setValuesForXI.groovy#L43].
