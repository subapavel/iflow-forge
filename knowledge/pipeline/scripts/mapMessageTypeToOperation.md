# mapMessageTypeToOperation

## Purpose

Finds the property named `SAP-MT2OP-<operation>` whose value equals property messageTypeFromXMLRoot and sets header SAP_SenderOperation to `<operation>`, also appending it to header customHeaderProperties [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/mapMessageTypeToOperation.groovy#L9] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/mapMessageTypeToOperation.groovy#L10] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/mapMessageTypeToOperation.groovy#L11] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/mapMessageTypeToOperation.groovy#L15] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/mapMessageTypeToOperation.groovy#L18] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/mapMessageTypeToOperation.groovy#L24] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/mapMessageTypeToOperation.groovy#L30].
Script step "Map Message Type to Operation" in the main process of the Step01 alo and eo templates and the Step03 template, right after the Content Modifier "Define Service Interface Operations", which sets SAP-MT2OP-Operation1 and SAP-MT2OP-Operation2 to the sample values MessageType1 and MessageType2 and messageTypeFromXMLRoot by XPath `/*/local-name()` [com.sap.integration.cloud.pipeline.v2.template.step01.inbound.processing.alo, step 4 "Define Service Interface Operations"] [com.sap.integration.cloud.pipeline.v2.template.step01.inbound.processing.eo, step 5 "Define Service Interface Operations"] [com.sap.integration.cloud.pipeline.v2.template.step03.inbound.conversion, step 3 "Define Service Interface Operations"].
