# fetchPayloadFromXProperty

## Purpose

Puts the payload saved by `storePayloadInXProperty.groovy` back into the body: the property payload as is when header isWellFormedXml is "true", otherwise Base64-decoded [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L7] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L12] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L13] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L15].
Script step "Fetch original payload" in the retry and custom error handling of Step02 inbound processing and Step06, "Get payload" in Step04, Step05 and the Step02 asynchronous runtime, and "Restore payload" in the latter (Used by).

## Inputs

- Header isWellFormedXml [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L6] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L7].
- Property payload [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L10] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L13] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L15], written by the store step of the same iFlow [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/storePayloadInXProperty.groovy#L13] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/storePayloadInXProperty.groovy#L15].

## Outputs

- Body = the property value when isWellFormedXml is "true" [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L13].
- Otherwise body = `properties.get("payload").decodeBase64()`, the decoded bytes [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L15].
- The property is kept; no header or property is set [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L18].

## Gotchas

- The branch follows the header at the time of the fetch, not at the time of the store [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L7] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L12]; both must see the same value (Gotchas of `storePayloadInXProperty.groovy`).
- Missing property payload: L13 passes the null value to setBody [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L13]; L15 calls `decodeBase64()` on it without the null-safe operator [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L15].
- The step name "Fetch original payload" (Step02 inbound, Step06) reads payload, not originalPayload [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L13] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, step 27 "Fetch original payload"]; originalPayload exists only in the Step02 asynchronous runtime [com.sap.integration.cloud.pipeline.v2.generic.step02.integrated.messaging.async, scripts/storeOriginalPayloadInXProperty.groovy#L13].
- Step02 sync does not ship the script; its Content Modifier "Get payload" sets the body from `${exchangeProperty.payload}` [com.sap.integration.cloud.pipeline.v2.generic.step02.integrated.messaging.sync, step 58 "Get payload"].
