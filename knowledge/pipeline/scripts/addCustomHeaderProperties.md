# addCustomHeaderProperties

## Purpose

Merges the entries of header customHeaderProperties and of the exchange properties `customHeader_<name>` into one map, writes every entry to the message processing log as a custom header property, and stores the map back in header customHeaderProperties as Base64-encoded JSON [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/addCustomHeaderProperties.groovy#L9] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/addCustomHeaderProperties.groovy#L11] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/addCustomHeaderProperties.groovy#L13] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/addCustomHeaderProperties.groovy#L43] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/addCustomHeaderProperties.groovy#L69] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/addCustomHeaderProperties.groovy#L72] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/addCustomHeaderProperties.groovy#L74] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/addCustomHeaderProperties.groovy#L75].
