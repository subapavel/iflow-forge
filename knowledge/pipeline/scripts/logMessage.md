Script step "Log Message per Config" in the exception handling of Step08 IDoc and Step08 XI, right after "Save in Audit Log" (Used by).

## Gotchas

- Tokens other than the eight above are ignored without a message [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/logMessage.groovy#L28] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/logMessage.groovy#L35] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/logMessage.groovy#L43] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/logMessage.groovy#L51].
- The exclusion lists are fixed [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/logMessage.groovy#L16] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/logMessage.groovy#L17]: any other header or property goes into the attachment as plain text when header or property logging is on.
- The excluded property auditLogProperty is the Step08 backup of the audit log [com.sap.integration.cloud.pipeline.v2.generic.step08.outbound.processing.idoc, step 27 "Backup Log headers"], so the audit log appears only in the AuditLog attachment.
- The media type comes from property mediaType, not from mplAttachmentMediaType as in auditLogHandler [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/logMessage.groovy#L14] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/auditLogHandler.groovy#L9]; mplAttachmentName is a prefix here [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/logMessage.groovy#L30] but a full name there [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/auditLogHandler.groovy#L8].
- The body is read as String also when no payload token is set [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/logMessage.groovy#L7].
- In Step08 "Save in Audit Log" runs first, so the AuditLog attachment already holds the exception entry [com.sap.integration.cloud.pipeline.v2.generic.step08.outbound.processing.idoc, step 20 "Save in Audit Log"] [com.sap.integration.cloud.pipeline.v2.generic.step08.outbound.processing.idoc, step 21 "Log Message per Config"] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/auditLogHandler.groovy#L36].
- In 2026-09 (collection 1.0.1) logMessage.groovy adds exception logging whenever CamelExceptionCaught is set and writes an ExceptionInfo attachment [2026-09: com.sap.integration.cloud.pipeline.v2.script.collection, scripts/logMessage.groovy#L29] [2026-09: com.sap.integration.cloud.pipeline.v2.script.collection, scripts/logMessage.groovy#L136] — see versions/2026-09/changelog.md.
