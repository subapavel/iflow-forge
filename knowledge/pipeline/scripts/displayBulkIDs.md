# displayBulkIDs

## Purpose

Writes IDoc numbers to the message processing log as custom header properties: the adapter's SapIDocDbId and SapIDocTransferId without leading zeros, and, for more than one node, every number of a node list either as one entry per number or as one JSON list [com.sap.integration.cloud.pipeline.v2.generic.step01.inbound.processing.idoc, scripts/displayBulkIDs.groovy#L21] [com.sap.integration.cloud.pipeline.v2.generic.step01.inbound.processing.idoc, scripts/displayBulkIDs.groovy#L26] [com.sap.integration.cloud.pipeline.v2.generic.step01.inbound.processing.idoc, scripts/displayBulkIDs.groovy#L40] [com.sap.integration.cloud.pipeline.v2.generic.step01.inbound.processing.idoc, scripts/displayBulkIDs.groovy#L62].
Script step "Set bulk IDs" in the main process of Step01 IDoc, before the router "Bulk?" [com.sap.integration.cloud.pipeline.v2.generic.step01.inbound.processing.idoc, step 27 "Bulk?"], and "Set IDoc Numbers" in the main process of Step08 IDoc, after the router "Content Type?" and its two send processes [com.sap.integration.cloud.pipeline.v2.generic.step08.outbound.processing.idoc, step 29 "Content Type?"].
