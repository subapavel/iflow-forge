# customReceiverDeterminationViaXProperties

## Purpose

Builds a Receivers XML from exchange properties: one Receiver for each property whose name contains "SAP-DYNREC-" and whose value is true or empty, written as `sys:Receivers` in namespace http://sap.com/xi/XI/System into the body [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L6] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L8] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L19] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L33] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L38] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L50] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L52] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L63].
Script step "Create Receivers XML" in the Step04 template for custom receiver and interface determination via exchange properties, after the Content Modifier that defines the conditions and before "Add interfaces to XML" (Used by).

## Gotchas

- Selection is Groovy truth of the value or the empty string [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L33], not a comparison with 'true'; the template's Boolean type gives true or false [com.sap.integration.cloud.pipeline.v2.template.step04.custom.receiver.determination.scripts, step 1 "Define receiver and interface conditions"].
- The name filter is `contains`, not a prefix test [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L8]; the receiver is cut at the last "-", so a receiver name containing "-" loses its first part [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L20] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L21].
- Operation-specific mode: L26 reads index 1 of the "~" split without a length check [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L25] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L26]; a key whose operation differs from SAP-Operation is skipped [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L28] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L29].
- Every Receiver carries SAP-Operation as Operation, also when operation-specific mode is off [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L24] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L36].
- No receiver selected: the body is an empty `sys:Receivers` element [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L50] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L51].
- The order of the receivers follows the key set of the properties [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L8] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/customReceiverDeterminationViaXProperties.groovy#L19].
- SAP-Operation and SAP-OperationSpecific are set by no step of the label (grep of every `.iflw` and Groovy script of the label: only the two ViaXProperties scripts name them).
