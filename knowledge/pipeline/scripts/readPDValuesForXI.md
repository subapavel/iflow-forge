Script step "Read PD values" in the main process of Step08 XI, after "Set Default Properties" (parameter defaults as `default_*` properties) and the router "XML?", and before "Set values for XI as properties", which resolves the final values [com.sap.integration.cloud.pipeline.v2.generic.step08.outbound.processing.xi, step 2 "Set Default Properties"] [com.sap.integration.cloud.pipeline.v2.generic.step08.outbound.processing.xi, step 4 "XML?"] [com.sap.integration.cloud.pipeline.v2.generic.step08.outbound.processing.xi, step 6 "Read PD values"] [com.sap.integration.cloud.pipeline.v2.generic.step08.outbound.processing.xi, step 7 "Set values for XI as properties"].
