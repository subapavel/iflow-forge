# auditLogHandler

## Purpose

Two functions around the audit log in header auditLogHeader: addAuditLog adds the text of property messageText as an entry and saves the log back to the header; attachAuditLog adds the entry in memory and attaches the whole log to the message processing log [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/auditLogHandler.groovy#L4] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/auditLogHandler.groovy#L6] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/auditLogHandler.groovy#L16] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/auditLogHandler.groovy#L22] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/auditLogHandler.groovy#L28] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/auditLogHandler.groovy#L36] [com.sap.integration.cloud.pipeline.v2.script.collection, scripts/auditLogHandler.groovy#L40].
Only addAuditLog runs in the label: Script step "Save in Audit Log" in the exception handling of Step08 IDoc and Step08 XI (Used by).
