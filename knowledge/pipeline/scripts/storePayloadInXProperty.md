# storePayloadInXProperty

## Purpose

Saves the message body in the exchange property payload: unchanged when header isWellFormedXml is "true", otherwise as Base64 text [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/storePayloadInXProperty.groovy#L6] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/storePayloadInXProperty.groovy#L12] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/storePayloadInXProperty.groovy#L13] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/storePayloadInXProperty.groovy#L15].
Script step "Store payload" right after "Check well formed XML" at the start of Step02 inbound processing, Step04, Step05 and Step06; in the Step02 asynchronous runtime "Store converted payload" after the second "Check well formed XML" that follows the inbound conversion (Used by).

## Inputs

- Body, read with `getBody()` without a type [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/storePayloadInXProperty.groovy#L6].
- Header isWellFormedXml [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/storePayloadInXProperty.groovy#L9] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/storePayloadInXProperty.groovy#L10], set to 'true' or 'false' by `checkWellFormedXML.groovy` in the step before [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/checkWellFormedXML.groovy#L8] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/checkWellFormedXML.groovy#L12].

## Outputs

- Property payload = the body object as returned by getBody() when isWellFormedXml is "true" [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/storePayloadInXProperty.groovy#L13].
- Otherwise property payload = `body.bytes.encodeBase64().toString()`, a Base64 String [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/storePayloadInXProperty.groovy#L15].
- Body and headers are not changed; the script throws no exception of its own [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/storePayloadInXProperty.groovy#L18].

- Only the Base64 branch converts the body; L13 stores the untyped object of L6 as is [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/storePayloadInXProperty.groovy#L6] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/storePayloadInXProperty.groovy#L13].
- The matching reader `fetchPayloadFromXProperty.groovy` decodes by the header it finds at its own run [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L12] [com.sap.integration.cloud.pipeline.v2.generic.step02.inbound.processing, scripts/fetchPayloadFromXProperty.groovy#L15]; in the shipping iFlows the only later "Check well formed XML" is Step02 async step 41, which runs before that iFlow's store step 42 [com.sap.integration.cloud.pipeline.v2.generic.step02.integrated.messaging.async, step 41 "Check well formed XML"] [com.sap.integration.cloud.pipeline.v2.generic.step02.integrated.messaging.async, step 42 "Store converted payload"].
