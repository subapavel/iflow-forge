# F-15 — Dossier v3 cannot hold several decision states of a real pilot

Date: 2026-10-27 · Task: MIG-38 · Spec: `docs/superpowers/plans/2026-10-26-migration-process-improvements.md` §P7

- **Assumption in the document:** an existing pilot can be represented as a dossier (plan §P7
  "Kompatibilita": the import report shows unresolved approvals), with supersession through an
  approved successor (`skills/sap-po-migration/references/dossier.md`, "Approval and current state").
- **How it fails in practice:** importing pilot M-1 (169 source records) met records the v3 shape
  cannot hold: a supersession by an unapproved or only partially approved successor, a partial
  deferral of a question, a "partially resolved" question, and an approval whose snapshot excerpt
  also contains a labelled recommendation. Importing such approvals as `approve` made the
  projection show superseded decisions as current (reviewer R r1, four blocking reasons). The
  honest import leaves them `approval-unresolved` or unresolved, so the dossier understates what
  the originals decided; only the import report shows the difference (61 of 169 unresolved, 4
  explicit approval wordings not imported).
- **Severity:** major
- **Evidence:** private audit view of M-1 (`local/<customer>/`, gitignored): import report,
  reviewer R r1 FAIL4 and r2 PASS, replay case 0 (valid, only `HISTORY_NOT_CHECKED`).
- **Change made:** none in code; MIG-40 adds `skills/sap-po-migration/references/legacy-import.md` (import rules, D-058).
- **Spec edit:** none (finding only; a design change is for the owner).
- **PROGRESS entry:** MIG-38 marked `Deviation: F-15`
- **For the owner's review:** whether v3 should gain events for partial supersession, partial
  deferral and question sub-states, or whether such records stay outside the dossier and the
  import report remains the place that shows them.
- **Owner decision (2026-10-27, D-058):** v3 stays unchanged; the gaps are closed by legacy import
  rules in the migration skill (MIG-40 packet `2026-10-27-mig-40-import-rules-packet.md`).
