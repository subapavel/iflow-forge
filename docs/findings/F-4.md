docs/superpowers/specs/2026-10-19-pipeline-knowledge-base-design.md §6 (size budget); CLAUDE.md "any page ≤ 1,500 words".

- **Assumption in the document:** plan Task 7 step 5 ends "Under 2,000 words." for `contracts.md`.
- **How it fails in practice:** the budget check (`Checks.budget`, `PAGE_LIMIT = 1500`, KB-03) fails any page over 1,500
  words, and `contracts.md` is part of the loaded set (≤ 5,000 with `SKILL.md`, `overview.md`, `scenario-contribution.md`);
  a 2,000-word `contracts.md` would turn `mvn verify` red and leave 3,000 words for the other three loaded pages.
- **Severity:** minor
- **Evidence:** iflow-forge-knowledge/src/test/java/io/iflowforge/knowledge/Checks.java line 39 (`PAGE_LIMIT = 1500`);
  CLAUDE.md "Page budgets"; spec §6 size budget.
- **Change made:** the plan line reads "Under 1,500 words (the page budget)". `contracts.md` is written as compact tables
  (name, set by, read by, one cite each); the `contractNames` check requires only that every name appears backticked on the
  page, so the prose stays on the script and iFlow pages. Nothing else changes.
