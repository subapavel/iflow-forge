# F-16 — The evidence reviewer role has no hashing tool

Date: 2026-10-27 · Task: MIG-38 · Spec: `skills/sap-po-migration/references/evidence.md` "Packet and review"

- **Assumption in the document:** an independent reviewer writes the review JSON, which names the
  packet's `packetSha256` (`evidence.md`; `DossierEvidence` review shape).
- **How it fails in practice:** the repository's `reviewer` agent has Read/Grep/Glob/Write/Edit but
  no shell, so it cannot measure `packetSha256`. In the M-1 replay (case 6a) it stopped; the
  architect measured the digest and passed it on, and the writer and the verifier re-measured it
  (match). The digest the reviewer signs is thus not measured by the reviewer.
- **Severity:** minor
- **Evidence:** MIG-38 step 3 hand-backs; private case 6a register/review digests 2/2 match
  (verifier log).
- **Change made:** none; independent re-measurement by writer and verifier recorded.
- **Spec edit:** none (minor)
- **PROGRESS entry:** MIG-38 marked `Deviation: F-16`
- **For the owner's review:** give the evidence-review role a hashing step (a verifier measures
  first and the reviewer reads the logged value), or accept the re-measurement as sufficient.
