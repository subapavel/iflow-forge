# F-9 — The profile's installed version: spec §8.1 names the MANIFEST Bundle-Version, features.md names the package CHANGELOG entry

Date: 2026-10-21 · Task: MIG-05 · Spec: docs/superpowers/specs/2026-10-20-migration-front-end-design.md §8.1

- **Assumption in the document:** §8.1 lists the profile section "installed pipeline versions per package (from
  `META-INF/MANIFEST.MF` Bundle-Version of the tenant's download, KB-11e)".
- **How it fails in practice:** writing `templates/profile.md` (MIG-05) against the KB-11e page: `versions/features.md`
  "How to read" defines a package's version as its `CHANGELOG.txt`'s first dated entry, and "The tenant's installed
  version" states that an artifact's Bundle-Version is a separate number (Step01 IDoc 1.0.8 under Generic Inbound 1.0.7
  in 2026-06-trial). A profile filled from the Bundle-Version would not match the version column the feature gate uses,
  so the version check of phase 3 (spec §10) would compare two different numberings.
- **Severity:** minor (the document is imprecise about which number; the intent — record the tenant's installed version
  per package and gate features on it — is kept; no mechanism changes).
- **Evidence:** kb-author hand-back of MIG-05 (features.md "How to read" L7, "The tenant's installed version" L72 opened);
  `knowledge/sources/README.md#L27` is the cited source of the CHANGELOG rule.
- **Change made:** `templates/profile.md` "Installed pipeline versions" takes the package version from the CHANGELOG entry
  (features.md "How to read") and records that the Bundle-Version is the artifact's own number; the four
  `{{tenant.pipeline.version.*}}` placeholders of naming.md hold the values.
- **Spec edit:** changelog line at the top of the spec and §8.1 reworded: "(the first dated entry of each package's
  `CHANGELOG.txt` in the tenant's download, `versions/features.md` "How to read"; an artifact's `META-INF/MANIFEST.MF`
  Bundle-Version is a separate number, KB-11e; F-9)".
- **PROGRESS entry:** MIG-05 marked `Deviation: F-9`
- **For the owner's review:** confirm that the tenant's download carries the CHANGELOG.txt per package (the trial and
  the 2026-09 download do); the alternative — gating on the Bundle-Version of each artifact — was rejected because the
  feature gate (KB-11e) is keyed by the package version.
