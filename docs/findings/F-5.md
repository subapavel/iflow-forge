# F-5 — `contracts.md` cannot hold the message path and the full name registry within 1,500 words

Date: 2026-10-20 · Task: KB-07 · Spec: docs/superpowers/specs/2026-10-19-pipeline-knowledge-base-design.md §6 (layout,
`contracts.md` = "headers, exchange properties, JMS queues, ProcessDirect endpoints between steps"); plan Task 7 step 5.

- **Assumption in the document:** one page `contracts.md` holds the message path (12 hops, adapter cites on both
  sides), every header and exchange-property name with set-by/read-by and a cite, the queues and endpoints, and the
  synchronous-path differences.
- **How it fails in practice:** the label `2026-06-trial` yields 222 contract names (D-021) and about 146 cites with
  full artifact ids (D-019; the page has no artifact of its own, so the short script form is not allowed). Names, table
  pipes and cites alone are about 1,200 words; with the Delete-row notes the kb-reviewer required (D-021), the page
  reached 1,796 words (BudgetTest: 1,801 against the limit of 1,500, CLAUDE.md "any page ≤ 1,500 words").
- **Severity:** minor (layout only; no fact or check changes)
- **Evidence:** target/kb-07-verify-r2.log (`contracts.md: 1801 words (limit 1500)`), target/kb-07-wc.txt;
  kb-reviewer round 1 (PROGRESS KB-07).
- **Change made:** the smallest change keeping the intent — the page is split. `contracts.md` stays the registry that
  `Checks.contractNames` reads (intro, *Headers*, *Exchange properties*, with the Delete-row notes on the rows); the new
  `message-path.md` holds *Message path*, *Queues and endpoints* and *Synchronous path*, cites unchanged. `contracts.md`
  points to it in its intro; `SKILL.md` gains a row for it. `message-path.md` is not part of the loaded set (`overview.md`
  summarises the path and links to it in KB-11). Rejected: raising the page limit (CLAUDE.md rule), dropping table pipes
  or spaces to lower the word count (gaming the check), dropping cites.
- **Document changes:** spec §6 layout gains `message-path.md`; plan Task 7 step 5 names both pages; changelog lines in
  both.
