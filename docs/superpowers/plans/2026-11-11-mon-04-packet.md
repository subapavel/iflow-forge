and the 12 methods; Step 1 tests `MonitoringClientLookupTest` (one envelope + parse test per

C. `ReadOnlySurfaceTest.noWriteOperationInSources` scans every file under `po-xray-*/src/main/**`
(all modules, not only core), located from the test's working directory up to the reactor root.

D. Carry-over from MON-03 review (binding, small):
1. `KeyResolver`: a found message without `messageKey` is not dropped silently — `NotFound` carries
   a reason (`record NotFound(String idOrKey, String reason)`), e.g. "message found but has no key".
   Tests in `KeyResolverTest` (new methods; adapt only the existing `NotFound` constructor calls if
   the record shape forces it, stating that in the hand-back).
2. `SearchResult`: a nil or missing `warning`/`displayPermissionWarning` is recorded in
   `otherFields` as `"(nil)"` / `"(missing)"` instead of only becoming false.
3. `LogResult`: items that are not `AuditLogEntryData` are kept in a new last component
   `Map<String,String> otherFields` (as `Response/<name>#n`).
