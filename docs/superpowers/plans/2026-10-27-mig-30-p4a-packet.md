## Extraction contract

Walk XML in document order. Each xs:schema (http://www.w3.org/2001/XMLSchema) and WSDL1.1
definitions (http://schemas.xmlsoap.org/wsdl/) is a distinct resource, including schemas inside WSDL.
Kinds are xsd and wsdl; sourcePath is caller argument, locator is stable indexed element path.
Serialized resource content retains the element subtree and needed namespace declarations.
XSD declarations: immediate named element, attribute, complexType, simpleType, group, attributeGroup;
kind is local element name, QName uses targetNamespace or empty namespace, never ESR namespace.
WSDL declarations: immediate named message, portType, binding, service, using targetNamespace.
Dependencies: immediate XSD import/include/redefine (namespace/schemaLocation) and WSDL import
(namespace/location); retain missing attributes as null, retain duplicates/order and exact evidence.
Foreign namespace lookalikes and local nested XSD element declarations are not top-level declarations.
No dependency is declared resolved in this parser; resolution/missing diagnostics belong to MIG-31.
IntegrationReader uses ContractResources on serialized ExternalDefinition content with sourcePath null;
no invented archive filename. Preserve direct definition OID/VC identity and full ifmextmes refs in all
operation/mapping endpoint ObjRefs. Existing DT/MT behavior, P3 matching and shared schema unchanged.
