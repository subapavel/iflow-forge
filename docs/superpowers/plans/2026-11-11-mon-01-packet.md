## Goal

Record, from the WSDL served by the QA system, the exact SOAP contract the client of MON-02..04 must
speak, as finding F-17. Anonymous WSDL reads only; no authenticated call, no operation call.

## Inputs

- QA and PROD system URLs: `url=` in the owner's `~/.po-xray/systems/<qa>.properties` and
  `<prod>.properties` (names given in the hand-off prompt, never written to tracked files).
- Spec §4 (the expected contract) and the plan's Global Constraints (namespaces, `AdapterFilter` order).

## Allowed paths

- Write: `local/<customer>/monitoring-probe/**` (gitignored; raw WSDL documents and notes),
  `docs/findings/F-17.md`.
- Edit only if F-17 contradicts it: spec §4 and its top changelog line; plan MON-02 field order line.
- Nothing else. No ledgers, no git, no `src/`, no Maven.

## Steps

1. One-line `curl -s -m 30` GETs, no credentials, into the private directory:
   QA `<url>/AdapterMessageMonitoring/basic?wsdl&mode=ws_policy&style=document`,
   `?wsdl=binding&style=document&mode=ws_policy`, `?wsdl=interface&style=document&mode=ws_policy`;
   PROD the same three documents. Record HTTP status and size of each.
2. From the interface WSDL of QA determine, by reading (Grep/Read with offsets, no scripts in any
   language other than one-line shell commands):
   a. for each of the 21 read operations and their `…Response`: the element's namespace, its child
      element names, types and order;
   b. for `AdapterFilter`, `MessageInterface`, `MessageParty`, `BusinessAttribute`, `Locale`,
      `AdapterFrameworkData`, `MessageSearchReturnValue`, `AuditLogEntryData`, `StatusDetail`,
      `IntegrationFlow`, `AttributeMetadata`: namespace, children in order, `minOccurs`/`nillable`,
      and base types (`extension base`) with the inherited children;
   c. the fault messages and their detail elements (`OperationFailedException`, `InvalidKeyException`);
   d. SOAP binding style, `soapAction`, endpoint path of the `basic` port.
3. Compare QA and PROD: same 24 operations and identical type definitions? List any difference.
4. Write `docs/findings/F-17.md` on `docs/findings/TEMPLATE.md`. Severity `minor` unless the WSDL
   contradicts spec §4 or the plan's pinned `AdapterFilter` order (then `major` and the edit above).
   The evidence line names the private directory as `local/<customer>/monitoring-probe/` only.
   Put the contract tables in an appendix section of F-17; it may exceed the template's length.

tracked edit. Namespaces, element and type names from SAP's WSDL are SAP product identifiers and
are allowed.
