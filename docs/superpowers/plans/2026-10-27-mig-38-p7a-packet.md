## Import rules (A2/A3)

- I1. Approval events exist only where an original records the owner's approval explicitly;
  each other proposal is a `propose` plus `approval-unresolved` event in A2 and a line in A3.
- I2. Questions, decisions, deferrals and supersessions keep the original's state and wording;
  a contradiction or typo in an original is reported in A3, never fixed.
- I3. Fields an original lacks: `at` = the date the original states, else `unknown` (never a
  file mtime); `owner` = the person role the original names, else `not recorded`; `topic` = the
  original's heading; `expectedEvidence`/`reviewAt` = the original's words or `not recorded`;
  classification = `unclassified` with `classificationSource` and `classificationReason`
  `not recorded`, unless the original states the affected scope. Never an invented value.
- I4. A record that the v3 shape cannot hold is unresolved in A3 with the reason.
- I5. `dossier-check A2` and `dossier-check --json A2` are run (`cases/0/`); errors are findings,
  not reasons to change an original. A2 is never edited after reviewer R's check.
